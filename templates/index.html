မြန်မာ AI Movie Recap

ရုပ်ရှင်အစမှအဆုံး ဇာတ်ကြောင်းရေးရန်

ဗီဒီယိုဖိုင်ကို AI သို့တင်ပြီး ဇာတ်ကွက်အစဉ်လိုက် မြန်မာ narration script ထုတ်ရန်။

မှတ်ချက် — အလုပ်လုပ်ဖို့ server ပေါ်တွင် Gemini API key ထည့်ထားရမည်။ အခမဲ့ quota နဲ့ hosting ကန့်သတ်ချက်ရှိနိုင်သည်။ AI က ရုပ်ရှင်တစ်ကားလုံးကို အပြည့်အဝဖုံးလွှမ်းကြောင်း အာမမခံနိုင်ပါ။ ကိုယ်ပိုင်/ခွင့်ပြုချက်ရှိသော ဗီဒီယိုများကိုသာ တင်ပါ။

၁။ ရုပ်ရှင်ဖိုင်ရွေးပါ

ဗီဒီယိုရွေးပြီး စတင်နိုင်ပါတယ်။ ဖိုင်ကြီးလျှင် အချိန်ကြာနိုင်ပါတယ်။

၂။ ထွက်လာသော Script

ဒီဗားရှင်းက script ထုတ်ပေးခြင်းကို အဓိကထားသည်။ MP3 narration နဲ့ MP4 တည်းဖြတ်ထုတ်ယူခြင်းကို သီးခြားအဆင့်အဖြစ် ဆက်တည်ဆောက်ရမည်။
